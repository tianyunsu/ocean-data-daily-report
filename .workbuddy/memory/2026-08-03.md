## 技术要点（本次新增/踩坑）

### 沙箱阻断 Python 出网
`check_urls_0803.py` 用 urllib + ssl 不验证做 HEAD/GET，**全部 WinError 10061（目标计算机积极拒绝）**。本环境沙箱阻断 Python 直接出网，但 WebSearch / WebFetch 工具可正常访问外网。
→ **结论**：链接可用性校验一律改用 WebFetch，不要再写 Python 探测脚本。

### generate_html_daily.py 不可用
该脚本第 8 行 `exec(content.split('def tr')[0])` 会执行 `feishu_write_doc.py` 头部的 `import requests`，本环境无 requests → ModuleNotFoundError。
→ **解法**：新建 `gen_html_0803.py`，用 `ast.literal_eval` 直接解析 SECTIONS 字符串（不触发任何 import），复用原 HTML 模板。此法可作为后续通用生成器。

### SECTIONS 替换（沿用括号计数法，验证有效）
`build_daily.py`：`find('SECTIONS = [')` → depth 计数找匹配 `]` → `repr(NEW_SECTIONS)` 整体替换 → `compile()` 校验后写回。
