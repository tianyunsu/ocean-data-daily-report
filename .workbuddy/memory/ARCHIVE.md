### 3.2 飞书文档堆积与空壳（2026-10-18 结案）

曾堆积 137 个日报文档，其中 89 个是同一天重复建的；且 `04-15 ~ 10-16` 期间的文档全是空壳（块数 = 1）。根因是每次运行都新建文档，且写入失败未回读校验。修复：`create_document_and_write()` 按标题 `海洋AI技术日报 YYYY-MM-DD` 命中即清空重写，未命中才新建；写完必须回读块数。详见 SKILL 陷阱 33。

飞书曾出现「HTTP 全 200 但 27 条链接全丢」的情况。由此确立铁律：第三方 API 必须①校验响应体 `code` ②回读落库结果，两者都通过才算成功。
